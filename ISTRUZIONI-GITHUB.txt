  https://mappa-3passi-preview.easy-peasy.site


TRASFERIRE SU RENDER (via GitHub):

  1. Crea un repository su github.com
  2. Carica TUTTI i file di questo pacchetto (root del repo)
     (NON caricare .env, node_modules, dist)
  3. Vai su render.com -> New -> Blueprint
  4. Collega il repository: Render legge render.yaml
     e crea il Web Service automaticamente.
     L'app didattica funziona SENZA database.
     (Auth/DB opzionali: vedi DEPLOY-RENDER.md Passo 4)

  Dettagli: DEPLOY-RENDER.md


RICOSTRUIRE L'APP CON L'IA (da GitHub):

  1. git clone https://github.com/<utente>/<repo>.git
  2. pnpm install
  3. pnpm check
  4. pnpm dev        (oppure pnpm build && pnpm start)

  Dettagli e varianti: GUIDA-IA.md
